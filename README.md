# davidngeiywa.github.io

Source of my portfolio — **https://davidngeiywa.github.io** — a hand-built static site with no framework and no build server.

- **Motion:** GSAP 3.15 (ScrollTrigger, SplitText, ScrambleText, Flip) and Lenis smooth scroll, choreographed per section — stacking case-study cards, a sticky horizontal product lab, a scroll-drawn process line and a cursor-following archive preview.
- **Hero:** a single full-screen WebGL shader (OGL) of drifting topographic noise that leans toward the cursor, paused when off-screen.
- **Calm by default:** reduced-motion users get a complete, static page; there's a Motion toggle in the footer. Layout shift during a full scroll measures ≈0.01–0.05.
- **Fast and safe:** self-hosted, preloaded variable fonts with metric-matched fallbacks; WebP screenshots with reserved dimensions; CDN scripts pinned with SRI hashes; no third-party trackers.
- **Generated, not hand-copied:** every page is built from a single content file, so case studies, the archive and share images stay in sync.

Press <kbd>Ctrl</kbd> + <kbd>G</kbd> on the site for the layout grid.
